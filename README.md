# Практична робота №3

## Опис роботи
У межах практичної роботи створено програму у середовищі Visual Studio 2022 з використанням Windows Forms.

У програмі реалізовано:
- обчислення периметра трикутника за введеними сторонами;
- відображення кнопки «Обчислити» після заповнення необхідних полів;
- обчислення суми перших N елементів ряду 1 + 1/2 + 1/3 + ... + 1/N;
- побудову таблиці значень функції y = 3x + 2 для x від -2 до 2 з кроком 0,5;
- очищення результатів;
- переходи між окремими формами програми;
- кнопки для завершення роботи з формами.

## Середовище розробки
- Visual Studio 2022
- C#
- Windows Forms
